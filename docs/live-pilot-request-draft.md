# ร่างหนังสือ/อีเมล — ขอทราบหลักเกณฑ์การเชื่อมต่อ ThaiPHC API (ยังไม่ได้ส่ง)

**สถานะ:** DRAFT FOR OFFICIAL REVIEW — ไม่ใช่หนังสือที่ส่งแล้วหรือได้รับอนุมัติ  
**ผู้รับที่เสนอ:** ผู้รับผิดชอบระบบสารสนเทศงานสุขภาพภาคประชาชน ผ่านกองสนับสนุนสุขภาพภาคประชาชน หรือหน่วยงานที่ได้รับมอบหมาย (โปรดให้หน่วยงานยืนยันผู้มีอำนาจก่อนส่งอย่างเป็นทางการ)

**เรื่อง:** ขอความอนุเคราะห์ยืนยันแนวทางและสิทธิ์เชื่อมต่อระบบ ThaiPHC API สำหรับอ่านข้อมูลรหัสตำบลในพื้นที่อำเภอสอง จังหวัดแพร่

**เรียน:** ผู้รับผิดชอบระบบ ThaiPHC / ผู้มีอำนาจพิจารณาอนุญาตการใช้ API

ด้วยสำนักงานสาธารณสุขอำเภอสอง จังหวัดแพร่ มีความประสงค์จะศึกษาความเป็นไปได้ในการเชื่อมโยงข้อมูลอ้างอิงทางภูมิศาสตร์จากระบบ ThaiPHC เพื่อสนับสนุนการตรวจสอบความถูกต้องของรหัสตำบลในการดำเนินงานด้านข้อมูลสุขภาพภาคประชาชน โดยจะดำเนินการด้วยวิธีเรียกข้อมูลด้วยตนเองเป็นครั้งคราว (Manual, Read-only) ภายใต้สิทธิ์ที่ได้รับอนุญาตเท่านั้น

ในระยะเริ่มต้น มีข้อเสนอเพื่อขอพิจารณาเพียงหนึ่งรายการ ได้แก่

- รูปแบบคำขอ: `GET`
- Endpoint: `/api/v1/lookups/subdistricts`
- ตัวกรอง: `district_code=5406` (อำเภอสอง จังหวัดแพร่)
- ลักษณะการดำเนินการ: ผู้ปฏิบัติงานสั่งเรียกด้วยตนเองเพียงหนึ่งครั้งในระยะทดลอง และตรวจเฉพาะโครงสร้างข้อมูล/จำนวนรายการในหน่วยความจำ
- ไม่จัดเก็บข้อมูลตอบกลับดิบ ไม่ดึงข้อมูลบุคคล และไม่ส่งต่อข้อมูลไปยัง Google Sheets หรือระบบอื่นในระยะทดลอง

จึงขอความอนุเคราะห์แจ้งแนวทางและเงื่อนไขดังต่อไปนี้

1. หน่วยงานหรือผู้มีอำนาจอนุญาตการเชื่อมต่อ ThaiPHC API และกระบวนการยื่นคำขอใช้งานอย่างเป็นทางการ
2. สามารถใช้ Bearer Token ที่ผู้ใช้ได้รับหลังเข้าสู่ระบบผ่าน Browser โดยคัดลอกมาป้อนในโปรแกรมภายในหน่วยงานด้วยตนเองเพื่อเรียก GET ได้หรือไม่ หากไม่ได้ ขอทราบวิธีออก Token สำหรับ API ที่ได้รับอนุญาตแทน
3. การอนุญาตสำหรับ Endpoint และขอบเขตพื้นที่ข้างต้น รวมถึงข้อกำหนดด้านบัญชีผู้ใช้และระดับสิทธิ์
4. ข้อจำกัดจำนวนครั้งในการเรียกข้อมูล ระยะเวลาใช้งานและการเพิกถอน Token การจำกัดอัตราเรียก รวมถึงข้อควรระวังด้านความมั่นคงปลอดภัย
5. หลักเกณฑ์เกี่ยวกับวัตถุประสงค์ การใช้ การแสดงผล และการจัดเก็บข้อมูลในระดับหน่วยงาน ตลอดจนเอกสารรับรองหรือเลขอ้างอิงการอนุญาตที่จำเป็น

ทั้งนี้ หน่วยงานจะยังไม่ดำเนินการเรียก ThaiPHC API ด้วยโปรแกรมหรือใช้ Bearer Token จริงจนกว่าจะได้รับคำยืนยันแนวทางการใช้งานที่อนุญาต และผ่านการพิจารณาด้านความปลอดภัยภายในหน่วยงานเรียบร้อยแล้ว

จึงเรียนมาเพื่อโปรดพิจารณาให้คำแนะนำ และหากไม่ใช่หน่วยงานผู้รับผิดชอบโดยตรง ขอความอนุเคราะห์ส่งเรื่องไปยังผู้ดูแลระบบหรือผู้มีอำนาจพิจารณาต่อไปด้วย จะขอบคุณยิ่ง
